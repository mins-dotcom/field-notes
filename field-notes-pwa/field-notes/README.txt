현장 조사 노트 (PWA)

이 폴더의 파일을 "https 주소"에 올려야 폰에서 GPS, 카메라, 오프라인 저장이 동작합니다.
파일을 폰에 그냥 열면(file://) 동작하지 않습니다.

[GitHub Pages로 올리는 방법]
1. github.com 가입 후 새 저장소(Repository)를 만듭니다. 공개(Public)로 만드세요.
2. 저장소 화면에서 "Add file > Upload files"를 눌러 이 폴더 안의 파일 5개를 모두 올리고 Commit 합니다.
   (index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png)
3. Settings > Pages에서 Branch를 main, 폴더를 / (root)로 정하고 Save 합니다.
4. 1~2분 뒤 https://아이디.github.io/저장소이름/ 주소가 생깁니다.

[폰에 설치]
1. 폰 크롬에서 위 주소를 엽니다. (인터넷 연결 필요, 처음 한 번)
2. 크롬 메뉴(점 3개) > "홈 화면에 추가" 또는 "앱 설치".
3. 설치 후 위치·카메라 권한 요청이 나오면 허용합니다.
4. 한 번 열어 본 뒤에는 인터넷이 없어도 앱이 열립니다.

[VWorld 위성지도]
1. vworld.kr에서 인증키를 발급받고, 사용 URL에 위 주소(아이디.github.io)를 등록합니다.
2. 앱의 더보기 > 지도 설정에 인증키를 입력합니다.

[알아둘 점]
- 기록은 각 폰에만 저장됩니다. 폰끼리 옮기려면 더보기 > 백업 파일 저장/불러오기를 쓰세요.
- 위성 배경지도는 인터넷이 있어야 보입니다. 오프라인에서는 기록, 사진, GPS, 불러온 KML/GPX 경로는 쓸 수 있습니다.
- 구글 위성 타일은 구글 지도 서비스 약관상 공식 방식이 아닙니다. 필요하면 VWorld나 Esri 위성을 쓰세요.
